\subsection{Open Loop: Feedforward}
Consider a rocket of mass $m$ moving through air of density $\rho$ (following motor burnout). Let $x$ be the vertical motion. We approximate the rocket to move in a purely vertical fashion, in order to simplify calculations. The differential equation governing the rocket's motion is
\begin{align}
	m\ddot x = -mg -\frac{\rho C_{D_{\rm rkt}}A_{\rm ref}}{2}\dot x^2
\end{align}
We rearrange to obtain
\begin{align}
	\ddot x  = -g-\xi\dot x^2~:~~~\xi \equiv \frac{\rho C_{D_{\rm rkt}}A_{\rm ref}}{2m}
\end{align}
Let $\Delta \equiv \left(t-t_{\rm apog}\right)$. This is a nonlinear differential equation without closed form, and so we seek to approximate its solution $x$ as follows, knowing that $\ddot x=-g$ and $\dot x=0$ at apogee:
\begin{align}
	\dot x(t)\approx a\Delta^3 + b\Delta^2 - g\Delta
\end{align}
so that
\begin{align}
	\ddot x(t) \approx 3a\Delta^2 + 2b\Delta - g
\end{align}
and 
\begin{align}
	x(t)&\approx \frac a4\Delta^4 + \frac b3\Delta^3 - \frac g2\Delta^2 + x_0
\end{align}
where $x_0$ is the height at apogee. 
\begin{figure}[H]
\centering
~\\[-6em]
\includegraphics[width=0.5\textwidth]{etc/airbrakes/plot_noAirbrakes.pdf}	
\caption{Fit $\tilde{\dot x}$ onto the {\color b blue} velocity function of time simulator output. 13 points between the two vertical dotted lines were used to find the fit, for $t_{\rm apog}=35.5\rm ~s$. {\color r Red} shows the derivative of the fit; {\color p purple} shows the integral, with $x_0$ calculated from the right dotted line intersection with the purple curve. The difference between the predicted apogee altitude $\tilde x_0$ and the true apogee altitude $x_0$ is 3.5 m.}
\end{figure}
\end{multicols}
\begin{multicols}{2}
From the figure at right we can deduce that this method is appropriate, assuming the $t_{\rm apog}$ apogee time can be properly estimated. For a linear least-squares fitter, the only kind feasible on the onboard flight computer, the $t_{\rm apog}$ must not be fitted at the same time as $a$ and $b$; a simulation output cannot be used either since this would prevent flexibility in case of turbulence or ill-modeled motor performance. Thus, we use the simulator output $_0t_{\rm apog}$ to generate three possibilities of apogee times, and fit a quintic to the acceleration of the following form to decide between the apogee times:
\begin{align}
	\tilde a(t) = a_0(t-t_{\rm apog})^5 - g
\end{align}
The correlation coefficient $R^2$ is used to choose the best apogee time out of $[_0t_{\rm apog}-1,~_0t_{\rm apog},~_0t_{\rm apog}+1]$. Then, a shift of $\tt AIRBRAKES\underline{~}T\underline{~}APOG\underline{~}FUDGEDIFF$ is introduced, since the cubic approximation above functions best with an overestimated $\tilde t_{\rm apog}$. Once the apogee time and altitude are correctly predicted, energy conservation is used to model the effect of the airbrakes on the apogee altitude\footnote{ Note that we approximate the apogee time as remaining unchanged.}. The work done on the rocket by some airbrakes area function of time $A(t)$ is 
\begin{align}
		W = \int F~dx = \int \frac{C_D\rho A(t)\dot x^2}{2}~dx 
\end{align}
This will correspond to a change in altitude $\Delta x$ in the rocket apogee height:
\begin{align}
	\int \frac{C_D\rho A(t)\dot x^2}{2}~dx  = mg(\Delta x)
\end{align}
A rapid change of variables using $\dot x dt = dx$ gives
\begin{align}
	\int \frac{C_D\rho A(t)\dot x^3}{2}~dt  = mg(\Delta x)
\end{align}
and so
\begin{align}
	\int A(t)\dot x^3~dt = \frac{2mg(\Delta x)}{C_D\rho}
\end{align}
We are free to choose a model for $A(t)$ that is convenient to integrate and also physically actuate on the rocket. In this vein, we choose $A(t)$ to be a constant $A_0$ with a small ramp that lasts a half-second. As the integration will be quite tedious, we ignore the ramp in deriving the required airbrakes area, as that will be accounted for in the ``fudge factor'' that also accounts for lack of pure vertical motion, as well as other simplified phenomena. 
\end{multicols}
\newpage
\noindent Thus, we solve
\begin{align}
	A_0 = \frac{2mg(\Delta x)}{C_D\rho} \left(\int\limits_{t_0}^{t_{\rm apog}} \left((a(t-t_{\rm apog})^3 + b(t-t_{\rm apog})^2 - g(t-t_{\rm apog})\right)^3~dt\right)^{-1}
\end{align}
The integral expression gives
\begin{align}
	\int\limits_{t_0}^{t_1}\dot x^3~dt = -\Bigg(
& \frac{a^{3}}{10}\,(t_0 - t_1)^{10}
+ \frac{a^{2} b}{3}\,(t_0 - t_1)^{9}
+ \frac{3ab^{2} - 3a^{2}g}{8}\,(t_0 - t_1)^{8}\nonumber \\
& + \frac{b^{3} - 6abg}{7}\,(t_0 - t_1)^{7}
+ \frac{ag^{2} - b^{2}g}{2}\,(t_0 - t_1)^{6}
+ \frac{3bg^{2}}{5}\,(t_0 - t_1)^{5}
- \frac{g^{3}}{4}\,(t_0 - t_1)^{4}
\Bigg)
\end{align}
and so if $T\equiv t_{\rm apog}-t_0$, 
\begin{align}
	A_0 = f\cdot \left(-\frac{2mg(\Delta x)}{C_D\rho}\cdot \frac{T^{-4}}{\frac{a^{3}}{10}\,T^{6} + \frac{a^{2} b}{3}\,T^{5} + \frac{3ab^{2} - 3a^{2}g}{8}\,T^{4} + \frac{b^{3} - 6abg}{7}\,T^{3} + \frac{ag^{2} - b^{2}g}{2}\,T^{2} + \frac{3bg^{2}}{5}\,T - \frac{g^{3}}{4}}\right)
\end{align}
where $f$ is the aforementioned ``fudge factor,'' whose value is generally close to 3, tuned prior to launch. The latest values appear in the table below:

\subsection{Closed Loop: Feedback}
We have decided that due to uncertainty in the true performance of the Airbrakes hardware, we include a feedback component. The main prerequisite for such a component is accurate projected altitude estimation. 

Using a similar energy-based calculation, we assume that the only work done in rocket vertical motion arises from drag. Take $\bs{\hat x}$ to be the upwards direction. The force balance thus gives
\begin{align}
	m\ddot x = -mg - \left(\frac{\rho C_{D_{\rm airbrakes}}A(t)}{2}+c\right)\dot x^2\label{forcebalance}
\end{align}
where $c$ is the drag magnitude of the rocket divided by $\dot x^2$:
\begin{align}
	c = \frac{F_{D_{\rm rocket}}}{\dot x^2} = \frac{\rho C_{D_{\rm rocket}}A_{\rm ref}}{2}
\end{align}
This a constant and can be evaluated prior to flight.
From the balance, we have that the work done by the total drag is
\begin{align}
	W_{\rm drag} = \int \limits_{h_0}^{h_f}-F_D~dx
\end{align}
Since $\dot x\neq 0$ in the open interval of integration (only at the bound), we can perform the following change of variables:
\begin{align}
	\ddot x = \frac{d\dot x}{dt} = \frac{d\dot x}{dx}\frac{dx}{dt} = \frac{d\dot x}{dx}\dot x~\Rightarrow~dx = \frac{\dot x}{\ddot x}d\dot x
\end{align}
This allows us to write the energy conservation equation below, for some initial state $\{x=h_0;\dot x = v_0\}$ to the final state $\{x=h_f,\dot x = 0\}$:
\begin{align}
	mgh_f = \frac 12mv_0^2 + mgh_0 + \int\limits_{v_0}^0 \left(-F_D\frac{\dot x}{\ddot x}\right)~d\dot x
\end{align}
From the force balance in (\ref{forcebalance}) and the drag force expression, we have that the integral becomes a functional depending on the airbrakes area profile $A(t)$. Let $\alpha(t) = (\rho C_{D_{\rm airbrakes}}A(t))/2$:
\begin{align}
	I[v_0,A(t)] = \int\limits_{v_0}^0 \frac{(\alpha_0+c)\dot x^3}{\displaystyle(\alpha_0+c)\frac{\dot x^2}{m} + g}~d\dot x
\end{align}
We choose a constant $A(t) = A_0$ (which implies $\alpha=\alpha_0 = (\rho C_{D_{\rm airbrakes}}A_0)/2$) as from the feedforward, which simplifies the functional to a simple function, of the form $I(v_0,A_0)$. Integration gives
\begin{align}
	I(v_0,A_0) &= \frac{m(\dot x^2(\alpha_0+c) - gm\ln(\dot x^2(\alpha_0+c)+gam)}{2(\alpha_0+c)}\biggr|_{v_0}^0 \\
	&= \frac m2\cdot gm\frac{-\ln (gm)}{\alpha_0 + c} - \frac m2\left(v_0^2 - gm\frac{\ln(v_0^2(\alpha_0+c)+gm)}{\alpha_0+c}\right)
\end{align}
The energy balance becomes
\begin{align}
	h_f = h_0 + \frac 12\frac{v_0^2}{g} + \frac{I(v_0,A)\vert_{v_0}^0}{mg}
\end{align}
Upon simplification, we obtain
\begin{align}
	\boxed{h_f(h_0,v_0,\alpha_0) = h_0 + \frac{m}{2(\alpha_0+c)}\ln\left(v_0^2\cdot \frac{\alpha_0+c}{gm}+1\right)}
\end{align}
The predicted height without airbrakes is given by this expression for $\alpha_0=0$. Note that we have again ignored the ramp phase, as this complicates the expression unnecessarily, as with the feedforward calculation.

We have unfortunately found that this method is not very accurate with the OpenRocket-calculated $C_{D_{\rm rocket}}$; as such, we have decided to introduce a ``fudge factor'' for the $C_D$ of the rocket, of the form
\begin{align}
{\tt rocketCd}~ \longrightarrow ~{\tt rocketCd * cFudge}
\end{align}
where
\begin{align}
	{\tt cFudge} = 8.99999871\times 10^{-6} \cdot h_{\rm target}^2 - 1.10354984\times 10^{-1}\cdot h_{\rm target} + 3.38925325\times 10^2
\end{align}
if $h_{\rm target}$ is expressed in meters. These coefficients were obtained from fitting a quadratic to tuned fudging coefficients over several target altitudes. This fudge factor appears to account for lack of taking turbulences, linear drag terms, and non-vertical motion into account. This fudge factor is calculated as soon as the target altitude $h_{\rm target}$ is decided upon.

We now wish to control the error $e\equiv h_{\rm target}-h_f$ to aim for zero. We propose the following block diagram:
\begin{figure}[H]
\centering
\includegraphics[width=0.65\textwidth]{etc/airbrakes/controlBlockDiag.pdf}	
\caption{Block Diagram for the proposed Airbrakes CL controller.}
\end{figure}

\noindent We first must find the system dynamics transfer function $G_p$. 

\noindent We linearize about the point $\alpha^*\leftrightarrow A^*$, the output of the feedforward algorithm in the previous section.
\begin{align}
	h_{\rm target} \approx h_f(\alpha^*) &= h_0 + \frac{m}{2(\alpha^*+c)}\ln\left(v_0^2\cdot \frac{\alpha^*+c}{gm}+1\right) \\[1em]
	\frac{\partial h_f}{\partial \alpha}\biggr|_{\alpha^*} &= \frac m2\left(-\frac{\displaystyle\ln\left(\frac{v_0^2}{gm}(c+\alpha^*)+1\right)}{(c+\alpha^*)^2} + \frac{v_0^2}{gm(c+\alpha^*)\left(\frac{v_0^2}{gm}(c+\alpha^*)+1\right)}\right)\\[1em]
	\Rightarrow h_f(\alpha) &\approx h_f(\alpha^*) + (\alpha-\alpha*)\frac{\partial h_f}{\partial \alpha}\biggr|_{\alpha^*}
\end{align} 
Let $\Delta A \equiv A-A^*$, and let $\Delta h_f = h_f-h_{\rm target}$. The transfer function is thus
\begin{align}
	\boxed{\frac{\Delta h_f}{\Delta A} = \frac{\partial h_f}{\partial A}\biggr|_{\alpha^*} = \frac{\partial h_f}{\partial \alpha}\biggr|_{\alpha^*}\frac{\partial \alpha}{\partial A} = \frac m2\left(-\frac{\displaystyle\ln\left(\frac{v_0^2}{gm}(c+\alpha^*)+1\right)}{(c+\alpha^*)^2} + \frac{v_0^2}{gm(c+\alpha^*)\left(\frac{v_0^2}{gm}(c+\alpha^*)+1\right)}\right)\frac{\rho C_D}{2}}
\end{align}
We calculate $\alpha^*$ from the feedforward $A^*$ in the previous section. 

We now propose the control scheme. An integrator is useful in removing steady state error, accumulated from a malperforming physical system. Let $K$ be
\begin{align}
	K = \frac{\partial h_f}{\partial A}\biggr|_{\alpha^*}
\end{align}
Thus,
\begin{align}
	\Delta h_f = K\Delta A~\Rightarrow~\Delta A = \frac{\Delta h_f}{K}
\end{align}
For a PI controller, we add one pole, such that
\begin{align}
	\Delta A = K_pe + K_i\int\limits_0^te~dt~\Rightarrow~0\approx \Delta h_f = K\left(K_pe + K_i\int\limits_0^te~dt\right)
\end{align}
We take the derivative:
\begin{align}
	0 = KK_p\dot e + KK_ie = KK_p\partial_t \Delta h_f +KK_i\Delta h_f~\Rightarrow~\partial_t\Delta h_f  = -\frac{KK_i}{1+KK_p}\Delta h_f
\end{align}
In frequency space, we have
\begin{align}
	s = -\frac{KK_i}{1+KK_p}
\end{align}
In time, we have a time constant of $\tau$ if the pole location is at $s=-1/\tau$. Thus, 
\begin{align}
	\frac{KK_i}{1+KK_p} = \frac 1\tau
\end{align}
Let $\beta = KK_p$. Thus,
\begin{align}
	K_p = \frac \beta K
\end{align}
As a function of $\tau$, the integrator gain $K_i$ is
\begin{align}
	K_i = \frac{1+\beta}{K\tau}
\end{align}
We have tuned these gains (starting from $\tau=\beta=1$) to
\begin{align}
	\boxed{K_p = \frac{2.5}{K}}\quad\quad;\quad\quad \boxed{K_i = \frac{1}{K}}
\end{align}
which corresponds to $\beta=2.5$ and $\tau = 3.5\rm~s$, exactly an overdamped behavior we desire (since it is very difficult (in fact more and more difficult over time) to recover an altitude loss). These were tuned with OpenRocket RK6 simulation, over several ``airbrakes malfunction factors'' which related commanded exposed area to actual (simulated) exposed area.


In continuous time, the control step is
\begin{align}
	A(t) = A^* + K_p(h_f(t)-h_{\rm target}) + K_i\int\limits_0^t (h_f(t)-h_{\rm target})~dt
\end{align}
The flight computer runs in discrete time, of course. In order to prevent windup, we implement this as
\begin{align}
	\boxed{A[k] = A^* + K_p(h_f[k]-h_{\rm target}) + K_i\left\{\begin{array}{ll}
I[k] & {\rm if~}	A[k]\geq 1{\rm~and~}\Delta h_f[k]>0 \\[.5em]
I[k]  & {\rm if~}A[k]\leq 0{\rm~and~}\Delta h_f[k]<0\\[.5em]
 I[k] + (h_f[k]-h_{\rm target}) & \rm otherwise
\end{array}
\right.}
\end{align}
This control portion is only applied in the ``plateau'' phase (see below), after the feedforward estimate is completed.
\subsection{Onboard Algorithm}
\noindent We have implemented the Airbrakes Control Algorithm using a state machine with the following states (encoded in {\tt AirbrakesControllerState}):
\begin{multicols}{4}
\begin{itemize}\tt
	\item {\color[HTML]{3C78D8}{\tt  DISABLED}}
	\item {\color[HTML]{A64D79}{\tt PREP}}
	\item {\color[HTML]{134F5C}{\tt PREPROCESS}}
	\item {\color[HTML]{38761D}{\tt WAIT\underline{~}FOR\underline{~}START}}
	\item {\color[HTML]{CD6666}{\tt CONTROLLING\underline{~}RAMP}}
	\item {\color[HTML]{96094F}{\tt CONTROLLING\underline{~}PLATEAU}}
	\item {\color[HTML]{08357E}{\tt DONE}}
	\item {\color[HTML]{AB0000}{\tt INFEASIBLE}}
\end{itemize}
\end{multicols}
\noindent Flow from one state to the next is governed according to the following diagram:
\begin{figure}[H]
\centering
\includegraphics[width=0.8\textwidth]{etc/airbrakes/statemachine2.pdf}	
\caption{Airbrakes Controlled State Flow.}
\end{figure}
\noindent We detail the exact procedure.
\begin{itemize}
	\item {\color[HTML]{3C78D8}\underline{\tt  DISABLED}}\\[.5em]
	The Airbrakes controller starts in this state. No action is taken until the method {\tt shouldStartAirbrakesControlPrep()} returns {\tt true}, namely
	\begin{lstlisting}[language=c++]
	return (getFlightTime() > EARLIEST_AIRBRAKES_PREP_TIME) && 
		   (!apogeeReached) && (currentRocketVel < START_AIRBRAKES_PREP_VEL)\end{lstlisting}
	\item {\color[HTML]{A64D79} \underline{\tt PREP}}\\[.5em]
	The {\tt PREP} stage consists of sampling velocity $\dot x(t)$ and acceleration $\ddot x(t)$ a total of $\tt nMeasurements$ times, with timestamps saved as well. Should the \verb|START_AIRBRAKES_PREPROC_TIME| marker have arrived prior to the full sample acquisition, the controller moves on to the {\tt PREPROCESS} state. \\
	\item {\color[HTML]{134F5C} \underline{\tt PREPROCESS}}\\[.5em]
	The {\tt PREPROCESS} stage consists of choosing the apogee time from the list of possibilities, according to the $R^2$ correlation coefficient of the quintic fit to acceleration ($y_i$ points). The quintic fit is conducted by linear least squares, according to
	\begin{align}
		\tilde a = \frac{\sum_i (y_i+g)(t_i-t_{\rm apog})^5}{\sum_i (t_i-t_{\rm apog})^{10}}
	\end{align}
	and
	\begin{align}
		R^2 = 1 - \frac{ \sum_i y_i - f(x_i;\tilde a)}{\sum_i(y_i-\overline y)^2}
	\end{align}
	The apogee time $t_{\rm apog}$ is decided to be $\tilde t_{\rm apog}+\tt AIRBRAKES\underline{~}T\underline{~}APOG\underline{~}FUDGEDIFF$. Next, the velocity is fitted to 
	\begin{align}
		\dot{x}(t) = a(t-t_{\rm apog})^3 + b(t-t_{\rm apog})^2 - g(t-t_{\rm apog})
	\end{align}
	This is again performed with linear least squares. The $X^TX$ matrix is
	\begin{align}
		X^TX = \begin{bmatrix}
			\displaystyle\sum_i(t_i-t_{\rm apog})^6 &&\displaystyle \sum_i(t_i-t_{\rm apog})^5 \\[2em]
			\displaystyle\sum_i(t_i-t_{\rm apog})^5 && \displaystyle\sum_i(t_i-t_{\rm apog})^4
		\end{bmatrix}
	\end{align}
	The $X^T\bs y$ matrix given by
	\begin{align}
		X^T\bs y = \begin{bmatrix}
		\displaystyle	\sum_i (t_i-t_{\rm apog})^3(\dot{x}_i + g(t_i-t_{\rm apog}))\\[2em]
			\displaystyle\sum_i (t_i-t_{\rm apog})^2(\dot{x}_i + g(t_i-t_{\rm apog}))
		\end{bmatrix}
	\end{align}
	The two parameters $\tilde a$ and $\tilde b$ are thus
	\begin{align}
		\begin{bmatrix}
			\tilde a \\ \tilde b
		\end{bmatrix} = \left(X^TX\right)^{-1}X^T\bs y
	\end{align}
	Next, the apogee altitude is obtained from
	\begin{align}
		x_0 = x(t_0) - \frac a4(t_0-t_{\rm apog})^4 + \frac b3(t_0-t_{\rm apog})^3 - \frac g2(t_0-t_{\rm apog})^2
	\end{align}
	The desired $\Delta x$ is obtained from the apogee prediction and the desired altitude, either obtained by rounding: 
	\begin{align}
		x_{\rm desired} = \left\lfloor \frac{x_0}{n}\right\rfloor n
	\end{align}
	where $n$ is some integer detailing the up-to-the-closest quantity to round to, or by a hardcoded value in the flight computer code. As of {\tt \color r FEB 17, 2026}, the target altitude is:
	\begin{align}
\nonumber		\color r\boxed{6275\rm~m}
	\end{align}
	The airbrakes start time is 
	\begin{align}
		\tt airbrakesCtrlStartTime = currentTime + AIRBRAKES\underline{~}TIME\underline{~}DELAY
	\end{align}
	The airbrakes area required is
	\begin{align}
		A_0 = {\tt reqDeployedAreaAirbrakes(currentTime+AIRBRAKES\underline{~}TIME\underline{~}DELAY,}~\Delta x)
	\end{align}
	Should $A_0 > 1$, the state progresses to {\color[HTML]{AB0000} \underline{\tt INFEASIBLE}}. Otherwise, the required $A_0$ is stored, and the state progresses to {\color[HTML]{38761D} \underline{\tt WAIT\underline{~}FOR\underline{~}START}}. The fudge factor {\tt cFudge} is now calculated according to
	\begin{align}
			{\tt cFudge} = 8.99999871\times 10^{-6} \cdot h_{\rm target}^2 - 1.10354984\times 10^{-1}\cdot h_{\rm target} + 3.38925325\times 10^2
	\end{align}
	\item {\color[HTML]{38761D} \underline{\tt WAIT\underline{~}FOR\underline{~}START}}\\[.5em]
	Simply wait for the flight time to be past {\tt airbrakesCtrlStartTime}. The state progresses to {\color[HTML]{CD6666} \underline{\tt CONTROLLING\underline{~}RAMP}}.\\
	\item {\color[HTML]{CD6666} \underline{\tt CONTROLLING\underline{~}RAMP}}\\[.5em]
	The airbrakes area $A(t)$ here is given by
	\begin{align}
		A(t) = 2A_0(t-{\tt airbrakesCtrlStartTime})
	\end{align}
	The state ends after 0.5 seconds, progressing to {\color[HTML]{96094F} \underline{\tt CONTROLLING\underline{~}PLATEAU}}.\\
	\item {\color[HTML]{96094F} \underline{\tt CONTROLLING\underline{~}PLATEAU}}\\[.5em]
	The airbrakes area $A(t)$ here is controlled using the algorithm detailed in the previous section. Concretely:
	\begin{enumerate}
		\item The airbrakes current area $A[k]$ is obtained, stored as {\tt lastA} (units are $\rm m^2$).
		\item The $\Delta A$ is computed as $A^*-A[k] = A_0-A[k]$, stored as {\tt lastDeltaA}.
		\item The projected altitude $h_f[k]$ is computed from the current altitude and velocity, obtained from onboard sensors. If the patching altitude has not yet been set, it is calculated and applied (this occurs once, at the first iteration in this state).
		\item The $\Delta h_f$ is computed as $h_f[k]-h_{\rm target}$, stored as {\tt lastDeltaH}. 
		\item The integral term is calculated:
		\begin{lstlisting}[language=c++]
float IofKplus1 = 0.0f;
if (((lastA >= 1.0f) && (lastDeltaH >= 0.0f)) || (lastA <= 1e-5f) && (lastDeltaH < 0.0f)) {
  IofKplus1 = lastI;
} else {
  IofKplus1 = lastI + 2.0f / K * lastDeltaH;
}
lastI = IofKplus1;\end{lstlisting}
		\item The next airbrakes area adjustment $\Delta A[k+1]$ is calculated as
		\begin{align}
			\Delta A[k+1] = K_p * {\tt lastDeltaH} + K_i * {\tt lastI}
		\end{align}
		and thus
		\begin{align}
			A[k+1] = \Delta A[k+1] + A^*
		\end{align}
		\item The airbrakes are set to the corresponding fraction:
		\begin{lstlisting}[language=c++]
setAirbrakesServo(nextA / a_max); // a_max = 0.0066 m^2\end{lstlisting}
		\item Should apogee have been detected, the state progresses to {\color[HTML]{08357E} \underline{\tt DONE}}.\\
	\end{enumerate}
	
	
	
	
	\item {\color[HTML]{08357E} \underline{\tt DONE}}\\[.5em]
	Nothing occurs in this state.\\
	\item {\color[HTML]{AB0000} \underline{\tt INFEASIBLE}}\\[.5em]
	Nothing occurs in this state.\\
\end{itemize}
