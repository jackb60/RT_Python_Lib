\section*{Instructions}
{\tt 
This manual is for use on Project Zephyrus flights, to be printed for launch in a minimum of $\boxed{\texttt{2}}$ copies, one for the Telemetry Lead, and another for the Telemetry Deputy. It is to be read prior to launch by all members involved in the Ground Station, Away Station, and Avionics/Structures Lead roles. At each of the Away Station(s) and Ground Station, $\boxed{\tt 2}$ copies must be printed and be available for the site lead and deputy to access prior to, during, and after flight. The personnel whose mastery of this document's contents is listed below:
\begin{itemize}
	\item \color r {\bf Avionics Lead}\hfill (Sections 1-9)\color k
	\item \color b{\bf Ground Station Lead}\hfill (Sections 1-2, 4-6, 8)\color k
